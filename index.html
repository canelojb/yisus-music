Cada canción tiene una puntuación de popularidad de Deezer (máximo cercano a 1.000.000). Con el filtro alto, las que superen el límite no se proponen, y además se buscan artistas pequeños y discos enteros, no solo sus éxitos. La puntuación aparece en cada canción para que ajustes el límite a tu gusto.

Reproducción

Videoclip completo de YouTube

Clave de la API de YouTube (opcional)

Sin clave, la app intenta encontrar el vídeo por su cuenta, pero puede fallar. Con clave es más fiable: en console.cloud.google.com crea un proyecto, activa «YouTube Data API v3», crea una clave de API y pégala aquí. Es gratis y da para unas 100 canciones nuevas al día.

Asistente con Claude

El asistente funciona sin nada, con respuestas básicas. Para que conteste con inteligencia artificial de verdad, pega una clave de API de Anthropic (console.anthropic.com). La clave se guarda solo en este navegador y la conversación se envía a Anthropic con tu clave; ponle un límite de gasto.

Copia de seguridad

Tus selecciones se guardan en este navegador. Descarga una copia para no perderlas o para pasarlas a otro dispositivo. La copia no incluye tus claves.
